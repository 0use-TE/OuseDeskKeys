# OuseDeskKeys

面向联想平板工作台模式的 Android 实体键盘快捷键工具。Kotlin + Jetpack Compose，支持系统、浅色、深色主题。

## 功能

- **Win + 1…9**：按工作台任务栏从左到右打开或切换应用，忽略应用列表、搜索等入口。
- 连接 Shizuku 并开启最小化功能后，再按当前聚焦应用对应的 **Win + 数字**可最小化窗口。
- **Win + D**：桌面与上次应用之间切换。
- **Ctrl + Alt + A**：调用系统全屏截图，使用系统预览与默认保存位置；截图快捷键可修改。
- **Ctrl + Alt + W**：关闭当前窗口；**Ctrl + Alt + M**：最小化当前窗口。两项均需 Shizuku 授权及对应开关。

窗口与任务栏快捷键仅在检测到联想工作台模式时启用。截图也可用于平板模式。不拦截 Ctrl + 数字；未匹配的按键继续交给系统或应用。

## 使用

1. 安装后在系统无障碍设置中启用 **OuseDeskKeys 桌面快捷键**。
2. 在应用中开启需要的功能。最小化和关闭窗口需先启动 Shizuku，再点击连接并授权。
3. Activity 可以关闭，无障碍服务由系统管理。重启后是否继续运行取决于系统设置；Shizuku 通过 ADB 启动时通常需要在重启后重新启动。

联想工作台识别依赖 `zui_ov_desktop_mode`，任务栏识别和窗口最小化依赖系统提供的节点与接口。其他设备或系统升级后不保证可用。关闭窗口移除的是对应任务，不会强制停止整个应用。

## 运行与加固

采用按键、窗口及包变化事件驱动，无定时扫描、轮询、网络访问或唤醒锁。应用名称索引按需在后台建立，应用变动或语言变化时失效；空闲工作线程自动退出。诊断记录仅保留内存中的最近 64 项。

Shizuku 连接有 12 秒超时，窗口请求有 1.5 秒超时；仅接受 750 毫秒内的操作请求。连接代次与操作令牌用于拒绝过期回调，窗口操作不会自动重试。权限检查及远程调用不在键盘过滤路径中同步执行。超时会断开旧服务，待旧调用回收后才能重连，避免持续堆积线程。已经进入系统的 Binder 调用不能保证撤销；系统或 Shizuku 本身卡住时可能需要重启 Shizuku。

事件驱动意味着空闲工作量较低，但实际耗电取决于设备与事件频率，没有“零耗电”或永不被系统结束的保证。

## 构建

需要 JDK 21、Android SDK 36，以及 SDK 路径配置（`ANDROID_HOME` 或本地 `local.properties`）。最低支持 Android 11。

```shell
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Windows 使用 `gradlew.bat`。APK 位于 `app/build/outputs/apk/debug/app-debug.apk`，调试签名由本机生成；覆盖安装既有版本时需要相同签名。

单元测试覆盖任务栏名称与通知徽标解析、同名应用处理、连接代次与超时失效、快捷键和窗口请求规则。实际工作台窗口行为需在设备上验证。
